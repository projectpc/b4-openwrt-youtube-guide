# Концепция дизайна: Руководство по проекту b4 для YouTube на OpenWrt

## Исследованные стилистические направления

### Направление 1: Cyberpunk Neon Terminal
- **Краткое описание**: Тёмный интерфейс с ярким неоновым свечением, имитирующий хакерскую консоль.
- **Вероятность**: 0.04

### Направление 2: OpenWrt Telemetry Lab (Выбранное направление)
- **Краткое описание**: Инженерный, высокоточный интерфейс сетевой лаборатории с технической эстетикой роутеров, чистой топологией, контрастной индикацией статусов и интерактивными калькуляторами стратегий DPI.
- **Вероятность**: 0.08

### Направление 3: Minimal Academic Monospace
- **Краткое описание**: Минималистичный текстовый справочник в стиле классических Unix man-pages и белых технической документации.
- **Вероятность**: 0.05

## Выбранное направление: OpenWrt Telemetry Lab

### Дизайн-движение
Инженерный скандинавский тек-дизайн с элементами аппаратных дашбордов сетевого оборудования enterprise-класса (Ubiquiti UniFi, MikroTik RouterOS v7 и GL.iNet Admin Panel), адаптированный для энтузиастов OpenWrt.

### Ключевые принципы
1. **Абсолютная техническая прозрачность**: Никаких размытых обещаний — точные команды CLI, понятные схемы пакетов, сравнение стратегий split/desync и конкретные флаги.
2. **Адаптация под MT6000 (Filogic 830)**: Акцент на 8-ядерную производительность ARMv8, разгрузку ядер, работу с nftables и ядром Linux 6.12.
3. **Интерактивность вместо сухого текста**: Интерактивный конфигуратор команд, генератор пресетов под YouTube, матрица стратегий DPI и встроенный чек-лист проверки работоспособности.

### Цветовая палитра
- Фоновый цвет: глубокий графитовый `oklch(0.18 0.02 260)` с микросеткой аппаратной лаборатории
- Карточки: матовый тёмно-синий сланец `oklch(0.22 0.025 255)` с тонкой рамкой `oklch(0.35 0.04 250)`
- Акцентный цвет (OpenWrt / Routing): яркий бирюзовый электролит `oklch(0.78 0.16 195)`
- Сигнальный YouTube красный: `oklch(0.62 0.23 25)`
- Сигнальный статус OK (Success): изумрудный `oklch(0.72 0.18 150)`
- Предупреждение (Warning): тёплый янтарный `oklch(0.8 0.16 85)`

### Типографика
- Заголовки: JetBrains Mono / Space Grotesk для строгого инженерного характера
- Основной текст: Inter / DM Sans для лёгкого чтения длинных технических инструкций
- Код и терминал: Fira Code / JetBrains Mono с подсветкой параметров

### Фирменные элементы
- Интерактивный CLI-билдер конфигурации под конкретные провайдеры РФ
- Сравнительная таблица стратегий b4 (split, fake, disorder, multisplit)
- Визуальная архитектурная диаграмма прохождения пакета в цепочке NFQUEUE / nftables роутера GL-MT6000
